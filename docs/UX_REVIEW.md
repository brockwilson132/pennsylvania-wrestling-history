# UX review — Overtime at 390×844 (before this pass)

What a first-time visitor saw in the first two screens of each page, what was confusing or clipped, what was redundant.

| Page | First two screens | Confusing / clipped | Redundant |
|---|---|---|---|
| State | Title, four hero tiles, a 5-line region bracket, then a 14-column table | Table's sticky name column slid over the scrolled numbers; nothing explained Era / Power until a paragraph below the table | Hero, bracket and table all restate state medals three ways |
| Region (NE) | Same shape as State | Same table overlap; region page also carried a second "Regional results" block with its own hero, table, teams and seasons | Two of every component (state and regional) on one page |
| District 11 | Bracket of schools, then the table | "District results" duplicated the whole page lower down; a reader had to know which block was which | As above |
| School (Nazareth) | Bracket of wrestlers, a 2×2 grid of trips / medal rate / first / latest, then a wide table | Bracket names ellipsized at 390 ("SEAN …", "TIM D…"); table numbers scrolled behind names | Trips grid repeated the hero; state, regional and district blocks each had their own all-time teams |
| Wrestlers | Search, then career cards | Only state placewinners existed; Trevor Tarsi (Nazareth, district and regional medalist, state qualifier) could not be found | — |
| Wrestler | Rating strip, best wins, career grid | First two seasons of a two-year career were blank, with no way to tell "did not compete" from "no data" | Long notes under every card |
| State bracket overlay | Field gauge, then entrant lines | Placers had to be read off the pills; no podium | Paragraph-length footnote |
| District bracket overlay | Same | Same | Same |

## The plan carried out

Five components, the same order on every level page: **header** (title, level switch, hero numbers, 8-step podium) → **bracket** → **rankings list** → **all-time team** → **seasons**. A single State · Regional · District switch replaces the separate lower-level blocks. Tables became one ranked list (sort chips choose the big number; an 8-cell strip shows medals by place). Notes are one line each; method text lives in About.
